# Repository guidance

- Inspect the source, README, tests, and Git status before editing.
- Preserve this repository's scope as a small in-memory phone directory demo. Do not add a database, authentication, or unrelated features unless requested.
- Add or update focused tests for API behavior changes. Keep tests isolated from the module-level directory state.
- Use synthetic example data only. Do not add real personal or patient data to code, tests, docs, or logs.
- Report the commands you ran and their results. State clearly when an environment limitation prevented verification.
